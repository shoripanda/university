# university

世界の大学に存在する珍しい学部・学科・研究科・学位課程・研究プログラムを紹介する一般向け書籍の制作リポジトリ。

本書の目的は「変わった学部」を並べることではなく、その学問がなぜ成立したのか、何を研究しているのか、どのような社会・産業・文化と結びついているのかを読み物として伝えることである。

## AI作業者へ
作業前に必ず `AGENTS.md` と `AI_INSTRUCTIONS.md` を読むこと。会話履歴や内部記憶ではなく、GitHub上の現行ファイルを正本として扱う。

## マニュアル
- `AGENTS.md` — AIエージェント入口規則
- `AI_INSTRUCTIONS.md` — 恒久的AI編集規則
- `BOOK_CONCEPT.md` — 本書の企画・読者・差別化
- `UNIVERSITY_SELECTION_CRITERIA.md` — 掲載候補の選定基準
- `SOURCE_HIERARCHY.md` — 情報源の信頼度階層
- `SOURCE_RESEARCH_MANUAL.md` — 調査手順
- `FACT_CHECK_MANUAL.md` — 事実確認規則
- `CITATION_BIBLIOGRAPHY_MANUAL.md` — 出典・書誌規則
- `WRITING_STYLE_MANUAL.md` — 一般書としての文章規則
- `CHAPTER_TEMPLATE.md` — 章の標準構造
- `ADVERSARIAL_REVIEW_MANUAL.md` — 敵対的検証手順
- `REVISION_WORKFLOW.md` — 改稿工程
- `FILE_VERSION_RULES.md` — ファイル・正本管理
- `ORIGINAL_NOTES_MANUAL.md` — 原注管理
- `FINAL_CHECKLIST.md` — 最終出版チェック

## 標準制作工程
候補調査 → 採否判断 → 事実検証 → 草稿 → 敵対的検証 → 改善 → 典拠再検証 → 全体編集 → 最終校正

## 最重要禁止事項
典拠や事実確認の作業を理由に、既存本文を勝手に削除・全面再構成・検証メモで上書きしないこと。
